## 1. 文档信息

- 产品形态：微信小程序
- 文档版本：V1.3 微信小程序生产准备版
- 更新日期：2026 年 8 月 27 日
- 需求来源：客户于 2026 年 8 月 16 日的微信沟通、客户提供的参考文档、`base.apk` 与 `base1.apk` 恢复源码
- 当前状态：小程序核心功能、本地测算、账号同步、咨询订单、专家排班运营接口、订单回查和微信支付 API v3 服务端流程已完成；备案 HTTPS 域名、正式微信参数和真实交易终验待外部提供

## 2. 项目目标

开发一款八字与紫微斗数排盘微信小程序。用户录入出生日期、出生时间、出生地点和性别后，系统完成历法与时辰处理，生成八字四柱、十神、大运流年、紫微十二宫、星曜、四化和基础解读结果，并提供每日运势、财富运程、六爻/求卦、八字合婚、名号测算、祈福明灯、心愿阁和真人咨询入口。

客户没有提供可直接运行的排盘算法或原始工程。本项目以两份 APK 的恢复源码、资源布局和规则表作为开发参考，在微信小程序中重新实现可测试的本地算法。恢复源码只作为规则和交互证据，不作为可直接编译的交付源码。

## 3. 目标用户与使用流程

### 3.1 目标用户

- 需要查询个人八字和紫微排盘结果的普通用户。
- 需要核对四柱、十神、星曜、四化和运势周期的命理从业者。

### 3.2 核心流程

1. 用户进入出生信息录入页。
2. 用户选择阳历或农历，填写日期、时间、地点或经度、性别。
3. 用户选择是否启用真太阳时、早晚子时和闰月处理。
4. 系统校验输入并完成时间归一化。
5. 系统生成八字和紫微排盘结果。
6. 用户在结果页分区查看八字、紫微、运势和基础解读。
7. 用户从首页进入每日运势、财富运程、六爻/求卦、合婚、名号、祈福或咨询功能。

## 4. 出生信息录入

### 4.1 输入字段

- 姓名或排盘备注，可选。
- 性别，必填。
- 历法类型：阳历或农历，必填。
- 出生日期和出生时间，必填。
- 农历闰月标记，仅农历输入时可选。
- 出生地点或经度，启用真太阳时时必填。
- 真太阳时开关。
- 子时口径：早子时或晚子时。

### 4.2 输入校验

- 拒绝不存在的阳历日期和超过当月天数的农历日期。
- 闰月必须与当年实际闰月一致。
- 时间范围为 `00:00-23:59`。
- 经度范围为 `-180` 至 `180`。
- 超出当前历法数据范围时明确提示，不静默生成结果。

## 5. 时间与历法处理

### 5.1 阳历与农历

- 支持阳历、农历双向转换。
- 支持农历闰月。
- 当前恢复数据覆盖范围在页面中明确提示。

### 5.2 真太阳时

- 根据出生地经度计算地方平太阳时修正。
- 增加均时差修正，输出最终采用的真太阳时。
- 显示原始时间、经度修正分钟、均时差分钟和最终时间。
- 真太阳时跨日或跨子时时，后续四柱和紫微计算使用修正后的时间。

### 5.3 早晚子时

- 支持早子时和晚子时两种日柱换日口径。
- 结果页显示本次排盘采用的子时口径。

## 6. 八字排盘

### 6.1 基础字段

- 年柱、月柱、日柱、时柱。
- 四柱天干、地支。
- 天干十神。
- 地支藏干及藏干十神。
- 四柱纳音。
- 五行数量统计。

### 6.2 运势周期

- 大运顺排或逆排。
- 起运年龄和每步大运年龄区间。
- 流年干支。
- 流月作为后续算法核验阶段内容。

### 6.3 神煞

- 展示本地规则已验证的神煞名称及所在柱位。
- 新增神煞规则必须记录来源并加入固定样例测试。
- 未从恢复源码或客户样例确认的神煞不显示为确定结果。

### 6.4 旺衰、喜用神和格局

- 产品保留五行旺衰、喜用神和格局的结果区域。
- 相关内容需要完整规则或客户认可的权威样例后进入正式计算。
- 在规则完成验证前，不使用简单五行计数替代旺衰、喜用神或格局结论。

## 7. 紫微斗数排盘

### 7.1 基础字段

- 命宫、身宫和五行局。
- 紫微十二宫。
- 十四主星。
- 已有辅星。
- 四化：化禄、化权、化科、化忌。
- 大限和流年命宫。

### 7.2 扩展字段

- 六吉星和六煞星。
- 星曜庙、旺、利、陷状态。
- 三方四正关联宫位。
- 紫微格局和流月列入后续规则核验阶段。

### 7.3 显示要求

- 每个宫位显示宫名、地支、主星、辅星、四化和大限。
- 有对应规则时显示星曜亮度状态。
- 三方四正只展示宫位关系；解释结论必须由已确认规则产生。

## 8. 基础解读

- 展示性格、事业、财运、感情和健康五类基础内容。
- 基础解读只能引用本次排盘已经生成的结构化字段。
- 文案标明“传统文化研究与娱乐参考”，不作保证性或决策性表述。
- 深度报告、AI 生成内容和付费解锁不在本次交付范围；页面不伪造支付成功或 AI 返回结果。

## 9. 红圈功能扩展

### 9.1 首页入口范围

本轮只加入参考图红圈中的功能：八字排盘、每日运势、祈福明灯、有事求卦、六爻排盘、八字合婚、财富运势/2026 财富运程、批 2026 好运/真人在线 1v1、名号测算、祈福好运/心愿阁。

不加入参考图未圈出的婚姻树、好运福袋、一生财运、招财树等功能。

### 9.2 每日运势与财富运程

- 输入：当前已保存命盘；没有命盘时引导先完成八字排盘。
- 输出：当日日期、综合提示、事业、财运、感情、健康、行动建议；财富页输出 2026 年度趋势和月份列表。
- 规则：内容由现有日主、五行统计、大运和流年结构化字段推导，标记为传统文化研究与娱乐参考。
- 验收：能从首页进入，能读取命盘并完成内容分区；命盘缺失时提示清晰。

### 9.3 有事求卦与六爻排盘

- 输入：所问事项、起卦时间；支持当前时间起卦和指定时间起卦。
- 规则：按恢复源码记录的时间起卦口径计算上卦、下卦和动爻，并展示计算依据。
- 输出：问题、起卦时间、上卦、下卦、动爻、卦象摘要和参考提示。
- 验收：同一时间输入得到稳定结果；时间非法时明确报错。

### 9.4 八字合婚

- 输入：男方和女方姓名、出生日期、出生时间、出生地点、经度和子时口径。
- 输出：双方四柱摘要、五行互补摘要、日主关系、关系参考分项和综合提示。
- 限制：评分为结构化参考，不作为确定性婚姻判断；客户提供基准样例后再调整流派规则。
- 验收：两方信息均完整时可生成；任一方缺失时阻止提交并提示字段。

### 9.5 名号测算

- 输入：姓名或待测名号，可选出生命盘；不再要求用户手动填写笔画。
- 输出：系统自动读取姓名字符的康熙笔画，展示字符明细、五格计算字段和三才结果。
- 数据：接入 `shunshi-ai/kangxi-mcp` 的常用字数据子集，保留 MIT 许可和来源版本记录。
- 限制：未收录字符明确提示“字库暂未收录”，不使用现代笔画或推测值替代。
- 验收：空姓名、超长姓名、繁体/异体字和缺字均有明确状态；“李明”自动识别为 7 画、8 画。

### 9.6 祈福明灯与心愿阁

- 输入：祈愿人姓名、心愿内容、类型和备注。
- 操作：创建明灯/心愿、查看列表、标记完成、删除本地记录。
- 存储：默认使用微信本地存储；配置后通过微信登录会话同步到后端 SQLite，记录带创建时间、状态和类型。
- 同步：支持远端列表读取、创建、完成状态更新和删除；登录或网络未配置时保留本地模式并明确显示状态。
- 限制：本地记录不等于线上点灯、支付或寺院服务订单。
- 验收：创建、查看、完成、删除流程可用，重新进入页面后记录仍存在。

### 9.7 批 2026 好运与真人在线 1v1

- 批 2026 好运进入年度财富/年度运势工具页。
- 真人在线 1v1 使用已配置的专家、价格和排班创建咨询订单，并保留微信客服入口。
- 当前入口不展示虚构的专家、价格、库存或支付状态；实际专家、排班和价格由运营配置接口提供。
- 已提供受 `ADMIN_TOKEN` 保护的运营配置页面，可维护专家和排班、查看订单并更新服务状态；支付状态只读，不能由运营页面改为已支付。

### 9.8 微信支付

- 支付范围：真人在线 1v1 咨询订单。
- 流程：登录用户选择已配置价格的专家，后端创建订单并向微信支付发起 JSAPI 下单，小程序调用 `wx.requestPayment`。
- 结果确认：以微信支付 API v3 支付通知为准，服务端验签、解密、校验订单金额并幂等更新订单状态。
- 状态展示：小程序在调起支付后进行有限次数的订单回查；达到上限后停止自动请求，并保留最近订单列表和手动刷新。
- 安全：商户私钥、API v3 Key、平台证书和商户参数只保存在服务器环境变量或证书文件中，不进入小程序和交付压缩包。
- 上线条件：微信小程序 AppID、微信支付商户号、商户证书/私钥、API v3 Key、平台证书、HTTPS 通知地址、支付主体资质和客户确认的咨询价格。

## 12. 非功能要求

- 核心排盘在小程序本地完成，不依赖旧 APK 服务。
- 输入错误必须明确提示，不得静默修正为其他日期。
- 算法模块与页面展示分离，单个 JavaScript 文件尽量不超过 300 行。
- 所有新增规则必须有自动化样例或边界测试。
- 日志与检查结果统一输出到项目 `logs` 目录。
- 后端记录接口要求 Bearer 会话；运营配置接口要求 `X-Admin-Token`，密钥只保存在服务器环境文件中。
- 账号、记录归属、更新状态和删除操作均进行服务端校验。
